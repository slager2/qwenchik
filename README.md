# Qwenchik

Локальная платформа длительных задач с Kanban, чатом и агентом на Go, рассчитанная на один локальный Qwen через OpenAI-compatible API.

## Направление реализации

Проект строится как local-first модульный монолит: Go backend, SQLite с durable events/checkpoints, один последовательный worker и web UI. Backend по умолчанию должен слушать только `127.0.0.1`; облачный LLM fallback и выполнение команд на хосте не допускаются.

Реализация ведётся по вертикальным фазам. Ближайшая проверяемая цель — создание задачи, сохранение состояния и событий в SQLite, управление lifecycle на backend и воспроизводимый поток SSE. Подключение модели и безопасного mock tool будет добавляться поверх этих контрактов.

## Статус

Начальная точка проекта. Аудит repository показал, что до bootstrap в каталоге не было кода, Git-репозитория или локальных инструкций `AGENTS.md`. Архитектурные решения и контракты фиксируются в `docs/` по мере реализации.
